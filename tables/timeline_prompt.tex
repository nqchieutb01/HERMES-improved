\caption{\textbf{Timeline-reasoning prompt vs.\ the official S-EMBER prompt} on S-EMBER grounded VideoQA (475 questions, 300 videos). Each row runs one memory configuration twice, changing only the prompt. \emph{Off.}: the official benchmark prompt (answer and interval directly). \emph{TL} (timeline): the model first lists up to 8 timestamped moments where the evidence is visible, derives the answer from them, and gives the interval from the first to the last moment. $\Delta$ = TL $-$ Off., green for a gain and red for a loss; bold when the 95\% paired bootstrap confidence interval over questions excludes zero. Acc.: answer accuracy judged with the official S-EMBER judge prompt; mIoU and R@0.5: temporal grounding; GQ@0.5: the answer is judged correct and its interval has IoU $\geq 0.5$. \emph{Streaming}: HERMES KV compression with no per-frame token floor; \emph{Timestamps}: whether a frame's timestamp tokens are kept while its visual tokens survive, or always. \emph{Offline}: one pruning pass after encoding keeps the given share of visual tokens: \emph{HERMES} by attention score, \emph{Random} at random, \emph{Stratified} an equal share of every frame; \emph{Spatial pooling} lowers the decode resolution instead (scale $s$ keeps $\approx s^2$ of the tokens). All numbers in \%.}
