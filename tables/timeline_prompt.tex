\caption{\textbf{Timeline-reasoning prompt vs.\ the official S-EMBER prompt} on S-EMBER grounded VideoQA (475 questions, 300 videos). Each row runs one memory configuration twice, changing only the prompt. \emph{Official}: the benchmark prompt (answer and interval directly). \emph{Timeline}: the model first lists up to 8 timestamped moments where the evidence is visible, derives the answer from them, and gives the interval from the first to the last moment. $\Delta$ = Timeline $-$ Official, green for a gain and red for a loss; bold when the 95\% paired bootstrap confidence interval over questions excludes zero. Acc.: answer accuracy judged with the official S-EMBER judge prompt; mIoU and R@0.5: temporal grounding. \emph{Streaming}: $k$ is the minimum number of tokens kept per frame; \emph{Timestamps}: whether a frame's timestamp tokens are kept while its visual tokens survive, or always. \emph{Offline}: one pruning pass after encoding keeps the given share of visual tokens; \emph{Stratified} keeps an equal share of every frame. All numbers in \%.}
