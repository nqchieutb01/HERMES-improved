Where it does not help, and what is still open

Base model below the floor

ActivityNet and Charades: even all tokens (22.9, 16.6) lose to a constant (37.9, 29.7). Claims there are relative.

Short, dense videos

Charades (30 s, ~2 frames per second): spreading tokens at random beats CoCo by 2.9 mIoU*.

Not a streaming memory

The memory is built per question with a full prefill; the cost table and a write-once memory are still to do.

Scope of the evidence

One model, 500-question subsets, a local judge; design chosen on S-EMBER (other datasets run once, frozen).

Next: SnapKV / PruneVid baselines, FV-Action and attention readout on the same memory, a second model, held-out S-EMBER.

* = 95% paired bootstrap excludes 0

The honest limits. On two standard benchmarks the base model is below a constant interval, so no compression method can claim absolute success there. On short videos, coverage by random spreading wins. The setting is query-time compression, not a persistent streaming memory, and the cost has not been measured yet. Everything is one model so far.
