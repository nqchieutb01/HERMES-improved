1 · The blind setup

The task: answer, and say when

Grounded question

“How long did I use the paper cutter?”
needs an answer and the time interval of its evidence.

The memory is expensive

64 frames ≈ 21,000 visual tokens. Pruners keep 10% and lose little on multiple-choice QA.

The answer format

Seen: 12.0 seconds, …
Seen: 41.0 seconds, …
Answer: about 29 s
Time: [12.0, 41.0]

Question: what happens to the time the model reports when most of the memory is gone?

S-EMBER grounded QA: 300 videos, 475 questions (duration, counting, location) · Qwen3-VL-8B · 64 frames

Setting: the model sees 64 frames up to the question time, encoded into a KV cache, pruned to 10% of the visual tokens. It answers with a timeline: timestamped observations, then the answer, then the interval. Metrics: mIoU and R@0.5 of the interval; GQ@0.5 = correct answer and IoU at least 0.5.
