Shared: one set for all 36 layers, as input-level pruners do (attention averaged over layers).

Random does not need per-layer diversity, so that is not why it beats the pruners.

Question-driven selection does: different layers attend to different evidence.

Random selection, seeds 0/1/2: 26.0 ± 0.6 mIoU, so gaps of 2+ points are not seed noise.

* = 95% paired bootstrap excludes 0; n.s. = not significant · bold blue = best, underline = second best per column

A fairness check against input-level pruners, which share one token set across layers. Sharing does not change random selection, so per-layer diversity does not explain random's advantage. For CoCo, sharing costs 1.5 mIoU, significant: per-layer selection is a small but real part of the method.
