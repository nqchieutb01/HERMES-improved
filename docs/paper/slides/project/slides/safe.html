Two refinements make the contrast safe

Time scope

Contrast only the time values (Seen: t, Time: [s, e]); decode the words greedily.

Contrasting every token changed the answer text in 85% of questions and raised over-counting from 14% to 34%.

Confidence-adaptive strength

α = 1 − max p(y | memory): the contrast fades where the memory makes the model sure.

Protects the 78 questions whose evidence really starts at 0 s.

Plain PCD pushes away from early times, which can hurt questions whose evidence really is at the start. The adaptive strength turns the contrast off where the memory is confident, and recovers those questions fully: accuracy 16.7 back to 23.1. The time scope keeps the answer words untouched.
