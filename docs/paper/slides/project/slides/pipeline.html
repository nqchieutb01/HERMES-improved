Coverage keeps every time anchor: fewer holes for the prior to fill.

Contrast removes the prior from whatever holes remain.

Training-free · no labelled calibration · no change to the model

The pipeline has two required parts, one for each failure from part 1. Coverage fixes the memory: every frame keeps its timestamp, and the question decides what each frame shows. Contrast fixes the decoder: the prior is removed where the memory is still silent. The answer reserve is a small format guard that PCD needs. Retrieval is optional; it adds less than one mIoU once tokens are chosen by the question.
