Before any comparison: grounding benchmarks have strong positional biases, as Otani et al. showed for Charades-STA and ActivityNet. A constant interval tuned on the test set beats the uncompressed model on three of four datasets. CoCo clears the floor on S-EMBER and QVHighlights; on ActivityNet and Charades the base model itself is below it, and so is every method.
