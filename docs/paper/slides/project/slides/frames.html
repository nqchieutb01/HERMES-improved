64 frames leave 2–4 tokens per frame pair: an equal quota then keeps tokens with little content, and CoCo collapses.

32 frames recover it: 9.7 → 43.1 and 11.6 → 33.9. Rule: keep ≥ ~8 tokens per frame pair (to validate on held-out data).

All with Contrast + reserve; low-resolution dataset copies (153 / ~84 tokens per frame pair) · bold blue = best, underline = second best per row

The collapse at tiny budgets is about how the budget is spent, not the method. With the same number of tokens, halving the frames doubles the tokens per frame, and CoCo goes from the worst method to the best. On ActivityNet, 32 frames at about 200 tokens nearly match 64 frames at three times the budget. The rule of thumb was derived from these runs, so it still needs held-out validation.
