The choice of counterfactual is what makes PCD work for grounding. The published VCD recipe contrasts against noised frames; it barely helps here because the noised memory still contains the prior. Contrasting against no video removes the prior directly. A penalty-only rule is much worse, because without video the model is almost certain of 0, so even a well-supported 0 looks like evidence against.
