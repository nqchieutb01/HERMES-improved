S-EMBER, 475 questions, empty visual memory, timeline prompt

The blind setup: we ask every question with an empty visual memory. The model never refuses; it writes a timeline anyway. Almost all of its answers start at 0 seconds and end too soon. This is the habit we call the temporal prior. The rest of part 1 shows it leaks into answers with video.
