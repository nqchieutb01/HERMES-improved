The answer reserve: a small guard PCD needs

PCD rewards fine time steps the prior finds unlikely, so it sometimes lists one activity second by second until the 384-token limit, and the interval is never written.

With 64 tokens left and no Answer: line, the decoder writes it and continues. The interval is still chosen by PCD.

The reserve is a format constraint, not a heuristic on content. It fixes a failure PCD itself causes: run-on lists of moments. Unparseable answers go to zero everywhere, and every PCD configuration improves significantly.
