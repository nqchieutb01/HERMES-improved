1 · The blind setup → PCD

Prior-contrastive decoding: subtract the blind answer

log p(y | memory) = log p(y | no video) + log [ p(y | memory) / p(y | no video) ]

prior + evidence from the memory

score(y) = (1+α) log p(y | memory) − α log p(y | no video)

= prior + (1+α) × evidence, among tokens with p(y | memory) ≥ 0.1 · max

The “no video” run uses the same prompt and prefix with no visual tokens: a cache of a few hundred tokens.

Probabilities on the right are illustrative (α = 1 − max p = 0.62); the decision matches the real teaser example

By Bayes, the model's log-probability is the video-free prior plus the evidence the memory adds. When the memory is silent the evidence term is flat and the prior decides. PCD amplifies the evidence term. The example on the right: the memory slightly prefers 0, but 0 is exactly what the blind model says; 64 is what only the memory supports, and PCD picks it.
