\section{Method: \method}
\label{sec:method}

\method intervenes where \cref{sec:diagnosis} found the failures. Coverage prunes the memory, prior-contrastive
decoding (PCD) corrects the decoder, and a frame-selection front end (BOLT) picks the input frames. No component
needs training (\cref{fig:overview}).

\subsection{Coverage: equal quotas filled by the question}
\label{sec:coverage}

After the $F$ frames are encoded, we prune the memory once, separately in each of the $L$ layers. Let
$\mathcal{T}_f$ be the visual tokens of frame pair $f \in \{1,\dots,F'\}$ and $B$ the per-layer budget for visual
tokens.

\paragraph{Question relevance.}
We append the question $x$ to the uncompressed memory and run it through all layers, so the queries at layer $\ell$
come from the real hidden states. Visual token $i$ is scored at layer $\ell$ by the attention it receives from the
question, averaged over heads $h$ and question positions $j$:
\begin{equation}
  a_\ell(i) \;=\; \frac{1}{H\,|x|} \sum_{h=1}^{H} \sum_{j \in x}
  \operatorname{softmax}_i\!\Big( \tfrac{1}{\sqrt{d}}\, Q^{(\ell,h)}_j \, {K^{(\ell,h)}_i}^{\!\top} \Big).
  \label{eq:relevance}
\end{equation}

\paragraph{Equal quota.}
Each frame pair gets $B_f = \lfloor B/F' \rfloor$ tokens, with any remainder handed out in order, and layer $\ell$
keeps
\begin{equation}
  \mathcal{K}_\ell \;=\; \bigcup_{f=1}^{F'} \topop_{B_f} \big\{\, a_\ell(i) \;:\; i \in \mathcal{T}_f \,\big\}.
  \label{eq:quota}
\end{equation}
The timestamp tokens of $f$ are kept if and only if $\mathcal{K}_\ell \cap \mathcal{T}_f \neq \emptyset$. At any
practical budget every frame pair keeps at least one token, so every time anchor survives, while the question
decides which part of each frame is shown. Kept tokens keep their original rotary positions and thus their temporal
order.

\paragraph{Why equal quotas.}
The equal quota is a deliberately simple constraint that guarantees the timeline and keeps attention from
collapsing onto a few frames. Under attention-mass quotas, sinks and recency bias can give one frame up to 227 of
the roughly 2{,}140 kept tokens, and in a pre-registered test relevance-weighted quotas with a floor did not beat
equal quotas ($-0.2$ mIoU). The quota matters most for generic probe scores as in HERMES~\cite{hermes}, which it
lifts by $5.3$ mIoU. With the actual question, a global top-$k$ without any quota has so far done as well
(\cref{sec:res-coverage}), so there the quota is a guarantee and not the source of the gain.

\paragraph{Per-layer selection.}
Each layer keeps its own set $\mathcal{K}_\ell$. Forcing one shared set by averaging attention over layers changes
\method by $-1.5$ mIoU and leaves random selection unaffected ($+0.7$). Per-layer selection thus helps
question-driven scores specifically and does not explain why random selection beats input-level pruners.

\paragraph{Frames and budget.}
With 2--4 tokens per frame pair, the most-attended tokens carry little content and Coverage collapses
(\cref{sec:frames}), so for small budgets we spend the tokens on fewer frames. At a fixed number of kept tokens, 32
frames with twice the share per frame recover what 64 frames lose. We use $F{=}64$ when each frame pair keeps at
least ${\sim}8$ tokens and halve $F$ otherwise. Kept timestamps count against the budget and take a large part of
budgets of a few hundred tokens, so some of the collapse may come from this accounting (\cref{sec:budget}).

\paragraph{Cost.}
Coverage adds one forward pass of the question over the uncompressed memory per question. Since the full memory is
prefilled first, Coverage shrinks the memory the decoder reads but not the cost of building it. PCD decodes a
second, prompt-only row in lockstep at every step, which roughly doubles the decoder's per-step work on a much

\subsection{PCD: prior-contrastive decoding of time values}
\label{sec:contrast}

Let $p_\Mem(y) = p(y \mid \Mem, x, y_{<t})$ be the next-token distribution with the compressed memory and
$p_\varnothing(y) = p(y \mid \varnothing, x, y_{<t})$ the distribution with the same prompt and generated prefix but
no visual tokens. Then
\begin{equation}
  \log p_\Mem(y) \;=\; \log p_\varnothing(y) \;+\; \underbrace{\log \frac{p_\Mem(y)}{p_\varnothing(y)}}_{\text{evidence from } \Mem},
  \label{eq:decomp}
\end{equation}
so when the memory says nothing about $y$, the evidence term is flat and the video-free prior decides
(\cref{sec:prior}). PCD amplifies the evidence term,
\begin{equation}
\begin{aligned}
  s_t(y) &\;=\; (1+\alpha_t)\log p_\Mem(y) - \alpha_t \log p_\varnothing(y) \\
         &\;=\; \log p_\varnothing(y) + (1+\alpha_t) \log \frac{p_\Mem(y)}{p_\varnothing(y)},
\end{aligned}
  \label{eq:pcd}
\end{equation}
and picks $y_t = \argmax_{y \in \mathcal{V}_\beta} s_t(y)$ over the plausible set
$\mathcal{V}_\beta = \{ y : p_\Mem(y) \geq \beta \max_{y'} p_\Mem(y') \}$ with $\beta{=}0.1$, as in VCD~\cite{vcd},
so tokens the memory makes implausible are never promoted. We adapt this rule to grounding in three ways.

\paragraph{No-video counterfactual.}
We use an empty negative memory instead of a noised or shuffled one. This isolates exactly the prior of
\cref{sec:prior}, and it is cheap, since its cache holds only the prompt.

\paragraph{Time scope.}
PCD is active only while the model writes a time value, inside a \texttt{Seen:} time and inside
\texttt{Time: [$s$, $e$]}. All other tokens, including the answer text, are decoded greedily from $p_\Mem$.

\paragraph{Confidence-adaptive strength.}
We set $\alpha_t = \alpha_{\max}\,\big(1 - \max_y p_\Mem(y)\big)$ with $\alpha_{\max}{=}1$. When the memory makes the
model confident, \eg because the evidence really starts at 0\,s, PCD fades out. When the model hesitates between
several times, the evidence term decides.

\paragraph{Prompt format and answer reserve.}
Under the timeline prompt, PCD acts first on the \texttt{Seen:} moments and then on the interval, which is thus
written from contrasted observations. With PCD, the last 64 tokens of the generation budget are reserved for the
\texttt{Answer:} and \texttt{Time:} lines, and the decoder starts an \texttt{Answer:} line once only 64 remain. The
reserve alone changes S-EMBER mIoU by only $+0.1$. A single-interval answer, as in the one-line prompt, leaves PCD
little to correct (\cref{sec:transfer}). Under the official prompt we have no clean PCD-only comparison on S-EMBER
yet, and on NExT-GQA PCD lowers the scored grounding by writing more times as minutes:seconds
(\cref{sec:res-contrast}).

\subsection{BOLT: question-guided frames}
\label{sec:retrieval}

When the window is much longer than $F$ frames, choosing the frames can matter as much as choosing the tokens. We
sample frames as in BOLT~\cite{bolt}. Each second of video is embedded once with SigLIP~2~\cite{siglip2}, giving a
causal 1\,fps index. The relevance $z_j$ of second $j \leq q$ is its z-scored
cosine similarity with the question, and the $F$ frames are taken at evenly spaced quantiles of
\begin{equation}
  p(j) \;=\; \tfrac{1}{2}\cdot\tfrac{1}{q} \;+\; \tfrac{1}{2}\operatorname{softmax}(z)_j ,
\end{equation}
so half of the frames remain uniform. We skip BOLT when uniform frames would be less than 1\,s apart. With
question-driven tokens, BOLT adds only $+0.8$ to $+0.9$ mIoU on S-EMBER, QVHighlights and ActivityNet. The runs in
the main tables include it.
